## 🔒 关于账号数据安全

发布包经过**自动泄露审计**（`Setup/audit-package.py`），确认不含任何账号数据：

- 账号只存在本机 `%APPDATA%\TsuruLauncher\config.json`，**不在程序目录**，
  所以打包 / 更新 / 重装都不会带上它
- 审计逐字节扫描 `publish/` 和 zip（含 UTF-8 + UTF-16 两种编码），
  比对**账号 UUID / 用户名 / 各类令牌 / 自有皮肤 SHA1**，并有**阳性对照**防止假阴性
- 打开发版统一走 `Setup/build-release.py`：干净发布 → 审计 → 打包 → 再审计，
  审计不过直接中止，不会产出包

> ⚠️ 注意：**不要**把 `%APPDATA%\TsuruLauncher\` 这个目录分享给别人（那里面才是账号）。
> 安装目录（`C:\Program Files\Tsuru Launcher`）是干净的，可以放心分享。

## 更新内容

这一版主要扩充了**实验室**，顺手修掉了皮肤页的两个老大难。

### 🧪 新增：AI 工具管理器

实验室里新增的一个工具，用来管理本机的 AI 命令行工具 —— 目前覆盖
**OpenClaw**、**Claude Code**、**DeepSeek Harness**：

- **一眼看清装没装** —— 每个工具带状态点（已装 / 未装 / 可更新），版本号直接从
  本机包目录的 `package.json` 读，不是写死的
- **检查更新** —— 走 `npm view` 查最新版，有新版会标出来
- **一键安装 / 更新** —— 直接在界面里跑，不用开终端
- **一键启动** —— 用 `cmd /k` 打开，窗口留着方便看输出
- **创建桌面快捷方式** —— 一次给所有已安装的工具建好

全部探测走本机 npm 全局目录（`%APPDATA%\npm`）与 `.dsh`，**不上传任何数据**。

### 📚 新增：NCRE 二级 Python 刷题

计算机二级 Python 的备考工具，直接嵌在启动器里：

- **620 道题**：464 道选择题 + 156 道操作题
- **章节刷题 + 限时模拟套题** —— 模拟卷按真实考试结构组卷
  （选择 40 分 = 公共基础 10 + Python 30；操作 60 分），120 分钟，交卷自动评分
- **「仅真题」筛选** —— 可以把非官方来源的题目滤掉，只做真题
- **错题本 + 章节正确率统计**
- **操作题真判题** —— 调用本机 Python 解释器跑一遍比对输出；带 `input()` 的题
  可以填「程序输入」，不用干等到超时

打开方式是**整窗覆盖**（盖住导航栏和右栏），左上角有「← 返回启动器」。
题库在 `Quiz/Data/*.json`，想换题直接替换这两个文件即可。

### ⚡ 皮肤页：修复首次打开卡顿

这个卡顿有两个叠加的原因，都修了：

- **`CoreWebView2Environment` 每次重建** —— 它是进程级重量级对象，创建时会拉起
  浏览器进程并占用 UI 线程，而这一下正好撞上页面转场动画，所以「一进皮肤页就卡住」。
  改为进程级单例 + 防重入。
- **首次创建皮肤页的同步开销**（XAML 解析 + 建控件树）也会卡住动画时钟。
  现在启动后空闲时会**提前预热**：拉起 WebView2 并预创建页面对象。

实测进皮肤页的初始化耗时从 **~2000ms 降到 ~40ms**，内容不再「猛地向上跳一下」。

### ✨ 动画与交互

- 皮肤卡片不再有第二段错峰平移，跟着页面进场一起动（之前是「页面先滑入、
  卡片再滑一次」，两段有时间差，观感上像卡了一下）
- 实验室工具列表从「一行一个大卡片」改成**三列网格**，一屏放得下全部工具

### 🐛 修复

- **修复列表整块空白** —— `ItemsControl` 的 `ItemTemplate` 里用带 `Storyboard` 的
  `Style` 时，WPF 无法 `Seal()` 这类 Style（每个列表项各自实例化），
  会导致整块列表渲染失败。改为转换器 + code-behind 附加属性做过渡。
- **AI 工具管理器不再误报「未安装」** —— 之前用 `ExpandEnvironmentVariables("%APPDATA%")`
  取路径，该变量为空时会拼出相对路径，导致明明装了也显示未安装。
- **桌面快捷方式修复** —— 之前用 WSH 晚期绑定写 `.lnk` 会抛
  `DISP_E_MEMBERNOTFOUND`，改用标准的 `IShellLink` COM 接口。
